소개

About

👋 박준서입니다

국민대학교 경영정보학부 1학년입니다. 경영학과 IT를 함께 배우며, 수업에서 배운 개념을 실제로 동작하는 웹 서비스로 만들어 보는 것에 관심이 많습니다. 최근에는 방문자가 작품에 응원을 남기면 그 기록이 서버에 저장되는 기능을 직접 만들었습니다.

🛠️ 최근에 만든 것

이 홈페이지의 작품 응원 보드를 직접 구현했습니다. 방문자가 버튼을 누르면 Netlify 서버 함수가 입력을 검사하고 Supabase 데이터베이스에 저장한 뒤, 집계를 다시 불러와 보여줍니다. 다른 기기에서 열어도 같은 응원 수가 보입니다.

  • 프런트엔드: HTML · CSS · JavaScript
  • 서버: Netlify Functions
  • 데이터: Supabase (Postgres)

📚 지금 배우는 것

데이터베이스와 시스템 분석·설계, 데이터 분석 기초를 배우고 있습니다. 배운 내용을 작은 프로젝트로 바로 연결해, 이론과 구현을 함께 익히려고 합니다.

👥 소속 학회

경영정보학부 학회 SITA에 소속되어 활동하고 있습니다. 학회에서 전공 지식을 함께 공부하고, 프로젝트와 교류를 통해 경험을 넓히고 있습니다.

🎯 지향점

데이터를 근거로 의사결정을 돕는 사람이 되는 것이 목표입니다. 복잡한 문제를 단순하고 실행 가능한 형태로 정리하고, 직접 만들어 검증하는 방식으로 일하고 싶습니다.
